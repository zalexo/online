How WindowHarbor outsmarts macOS display amnesia

When you yank a Thunderbolt cable, macOS dumps every window and Fullscreen Space onto your laptop screen. When you plug back in, macOS leaves Fullscreen Spaces stranded on the laptop. WindowHarbor fixes this without freezing your Mac or stealing focus.

Instant Freeze

The first hardware display callback advances a lock-free epoch and locks the learning gate so laptop-collapse frames never overwrite your 3-display profile.

Passive Space Radar

Reads macOS's public com.apple.spaces.plist in under 1 ms to see which monitor owns every Fullscreen Space across your entire system without switching Spaces.

Cross-Relaunch Rebind

Rebooted your Mac or restarted IntelliJ? Two-stage matching rebinds saved placements to fresh windows by unique accessibility ID, mode, and normalized geometry.

Lazy Space Catch-Up

Never hijacks your screen with forced app-switching loops. Visible windows restore immediately; hidden Spaces restore in 0.35s the moment you click or swipe into them.

Fullscreen Space relocation & Space-Safe Maximize

When a native Fullscreen Space gets stranded on your built-in display after cable replug, WindowHarbor exits fullscreen on the active Space, moves the window to its saved external monitor, and re-enters fullscreen (or converts it into a fast, Space-safe maximized window with zero animation lag).

Two-stage persistent window matching

Within a live session, windows match by exact (PID, launchDate, AXUIElement). Across app or Mac restarts, WindowHarbor deduplicates stale entries and rebinds saved placements to live windows using strict mode guards so a popup window can never steal a Fullscreen Space slot.

Built like a system daemon, polite like a guest

Pure Swift and AppKit. Zero third-party dependencies, zero private WindowServer hacks, and strict three-queue isolation so a slow disk write or hung app never stutters your cursor.

Three-Queue Isolation SIP Intact

Never blocks your main thread or hangs WindowServer

Accessibility IPC is synchronous cross-process messaging: running it on the main thread or on a concurrent queue freezes both the utility and the target app. WindowHarbor isolates all AX calls onto a single serial queue with a hard 0.25s timeout per element, while keeping JSON writes and zip archiving on a separate background queue.

Main Thread (.main) AppKit menu, NSScreen snapshots, Space/App notifications (zero AX IPC)
app.windowharbor.accessibility Serial AX IPC queue + live AXUIElement cache (0.25s timeout)
app.windowharbor.profile Serial disk queue: atomic profiles.json, .backup, 2 MB trace.log
100% Local & Title-Blind

Strict privacy by construction

WindowHarbor never reads, logs, or saves window titles, document URLs, browser tabs, or screenshots. Even when inspecting com.apple.spaces.plist, window title fields are ignored.

Bulletproof Storage

Atomic backups & one-click diagnostics

Every profile update backs up the previous file to profiles.json.backup inside a 0700 folder before atomic replacement. Need to debug a tricky dock transition? Click Archive Diagnostic Logs... to bundle anonymized trace logs and install the bundled macOS Spaces logging profile right from the menu.

No Startup Jumps

Calm startup adoption, delayed verification, and Undo

Launching WindowHarbor adopts your current screen setup in place without rearranging a single window. After any monitor hotplug restore, a 1-second verification pass quarantines windows that resisted resizing so bad frames never pollute your profile, and Undo Last Restore reverts the last pass in one click.

Floating, Maximized, and Native Fullscreen Space memory

Learns all three window modes per multi-monitor arrangement. Passively tracks Fullscreen Spaces across all monitors via com.apple.spaces.plist and retains live AXUIElement handles across Desktop Spaces.

Cross-relaunch window rebinding & duplicate cleanup

Automatically deduplicates stale session entries on load and rebinds saved placements to newly launched app windows by unique AXIdentifier, strict mode compatibility, and normalized frame similarity.

Lazy on-demand Space restoration & Fullscreen relocation

Restores visible windows immediately on monitor reconnect and catches hidden Spaces within 0.35s when you click or swipe into them, relocating stranded Fullscreen Spaces to their target external monitor.

Honest macOS public-API limits

By Design

No background fullscreen exit on hidden Spaces

macOS Dock ignores fullscreen exit requests unless that Fullscreen Space is currently visible on screen. WindowHarbor relocates a stranded Fullscreen Space when it is visible on a display, never by blindly cycling focus across all apps.

Identical untitled multi-window heuristics

Because WindowHarbor never reads private window titles or document URLs, two identically sized windows of the same app with generic accessibility IDs are matched by geometry and recency rather than document title.

Display UUID changes across different dock ports

Profiles are keyed by exact hardware display UUIDs and point geometry. Plugging the same monitor into a different Thunderbolt controller that assigns a new UUID creates a separate profile.

Install in 60 seconds

Requires macOS 14.0 (Sonoma) or newer. Download the prebuilt app bundle or build from source with Swift Package Manager.

Option A: Prebuilt App

Download WindowHarbor-macOS.zip

Ready-to-run release bundle with the embedded macOS Extended Spaces Logging profile.

  1. 1. Move to Applications: Download WindowHarbor-macOS.zip from GitHub Releases, unzip, and drag WindowHarbor.app into /Applications.
  2. 2. Allow first launch: Open System Settings → Privacy & Security and click Open Anyway (or strip quarantine via xattr -dr com.apple.quarantine /Applications/WindowHarbor.app).
  3. 3. Grant Accessibility & Logging Profile: On launch, WindowHarbor prompts for Accessibility access and opens System Settings → Device Management if the Extended Spaces Logging profile is not yet installed.
Download Release Tray icon turns from ⚠️ to rectangle.3.group automatically.
Option B: Build from Source

Compile with Swift Package Manager

Clone the repository, run all 58 Swift Testing unit tests, and build a local release .app bundle and .zip archive.

zsh: macOS 14+ / Swift 6 toolchain 
git clone https://github.com/zalexo/WindowHarbor.git
cd WindowHarbor
./scripts/test.sh
./scripts/build-app.sh
open dist/WindowHarbor.app

Tip: Pass SIGNING_IDENTITY="Developer ID Application: ..." to ./scripts/build-app.sh to keep a stable TCC Accessibility signature across local rebuilds.
